# String Calculator

문자열 덧셈 계산기 프로젝트  
Java 21, 프리코스 과제

---

## 프로젝트 개요

사용자가 입력한 문자열에서 숫자를 추출하고, 구분자를 기준으로 숫자를 합산하는 계산기입니다.
- 기본 구분자: 쉼표(,), 콜론(:)
- 커스텀 구분자 지원: "//(delimiter)\n" 형식
- 잘못된 입력 시 IllegalArgumentException 발생

---

## 기능 목록 및 커밋 메시지 예시

1. **빈 문자열 처리**
    - 입력이 빈 문자열("")이면 0 반환
    

2. **기본 구분자 처리 (, :)**
    - 쉼표와 콜론으로 구분된 숫자 합산
    

3. **커스텀 구분자 처리**
    - "//<delimiter>\n" 형식으로 지정된 구분자 사용
    

4. **잘못된 입력 예외 처리**
    - 숫자가 아닌 값 입력 시 `IllegalArgumentException` 발생
    

5. **결과 출력**
    - 합산 결과를 `"결과 : <sum>"` 형태로 출력
